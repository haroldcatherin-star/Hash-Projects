# Typographie

## Inter : la police de Fonsai

Une seule famille pour tout : titres, textes, interface. Gratuite et open source.
Téléchargement : https://fonts.google.com/specimen/Inter

| Usage | Graisse | Réglages |
|---|---|---|
| Grands titres | ExtraBold 800 | interlettrage −4 %, interligne 1,0 |
| Sous-titres | Bold 700 | interlettrage −2 % |
| Accroches, sur-titres | SemiBold 600 | couleur Soleil texte `#C7472F` |
| Texte courant | Regular 400 / Medium 500 | interligne 1,55 à 1,6 |
| Boutons | SemiBold 600 | phrase courte, verbe d'abord |

## JetBrains Mono : les chiffres

Pour les minuteurs, les heures, les statistiques et les codes couleur (`25:00`, `13,58/20`, `#1E3A2B`).
Téléchargement : https://fonts.google.com/specimen/JetBrains+Mono

## Le logotype

Le mot « Fonsai » du logo est composé en Inter ExtraBold 800, interlettrage −4 %, couleur Vert Fonsai `#1E3A2B` (ou Papier `#EDE3CC` sur fond sombre). Pour le logo, utilise toujours les fichiers de `01-logos/logotype/` plutôt que de le retaper.
