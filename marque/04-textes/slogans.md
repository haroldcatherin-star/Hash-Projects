# Slogans et accroches

## Signature officielle

**Fonsai, make focus addictive.**

C'est la seule signature de marque. Elle accompagne le logo sur l'image de partage, le site, les bannières et les documents.

## Accroches (pour le site, les posts, les vidéos)

Elles ne remplacent pas la signature : elles la déclinent selon le contexte.

| Accroche | Quand l'utiliser |
|---|---|
| Tout ton semestre. Une seule app. | Présenter le côté « tout-en-un » |
| Chaque minute de concentration fait pousser ton île. | Présenter le jeu de l'île |
| Une minute de focus = une brique. | Post court, vidéo, story |
| Bosse. Construis. Recommence. | Vidéo, TikTok, ton énergique |
| Ton île grandit quand tu travailles. | Accroche publicitaire, bannière |
| Lock in. | Lancer une session de focus, ton complice |
| Fini de jongler entre 5 applis. | Comparer avec les autres outils |
| La régularité, récompensée. | Parler des séries de jours |

## À éviter

- Traduire la signature mot à mot (« Rendez le focus addictif ») : elle reste en anglais.
- Les promesses qu'on ne peut pas tenir (« +5 points de moyenne garantis »).
- Les superlatifs vides (« la meilleure app du monde », « révolutionnaire »).
